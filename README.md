# SP Innovate Solutions

> Production-ready corporate website for **SP Innovate Solutions** — Enterprise System Integrations, Cloud Solutions, SaaS & API Architecture, Data Pipelines, and Workflow Automation.

Built with [Next.js](https://nextjs.org/) (App Router), TypeScript, Tailwind CSS, and Framer Motion.

---

## 🚀 Key Features & Pages

- **Global Navigation & Layout:** Responsive sticky navbar with services dropdown, mobile navigation drawer, dark/light mode toggle (`next-themes`), and 30-min architecture consultation modal.
- **Home (`/`):** High-converting hero section with dynamic live integration topology card, 4 core integration pillars, 4-stage interactive workflow, client case studies, executive testimonials, and closing CTA.
- **About Us (`/about`):** Heritage, mission & vision, core engineering principles, milestone journey timeline, and leadership team.
- **Services (`/services`):** Deep-dive capability cards for API & Middleware, Cloud DevOps, Legacy Modernization, Real-Time Data Pipelines, and Custom SaaS Engineering, plus expandable integration FAQ accordion.
- **Case Studies (`/case-studies`):** Filterable portfolio tabs (FinTech, E-commerce, Logistics, Healthcare, SaaS) featuring problem, solution, tech stack, and quantitative ROI metrics.
- **Contact (`/contact`):** Comprehensive consultation form (Zod validation + React Hook Form), interactive 30-minute discovery call scheduler, direct office details, and Google Maps preview.
- **Secondary Pages:** Privacy Policy (`/privacy`), Terms of Service (`/terms`), and Custom 404 (`/_not-found`).

---

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router + Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Forms & Validation:** React Hook Form + Zod
- **Theming:** `next-themes` (Default: Light Mode with Dark Mode support)

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/amangaurav1410/spinnovatesolutions.git
cd spinnovatesolutions

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

---

## 📦 Building for Production

```bash
npm run build
npm run start
```
